# 安全模型

首版代理能力白名单仅含 `READ`、`ANALYZE`、`CREATE_DRAFT`。`MUTATE_FORMAL_STATE` 与 `TRADE_RELATED` 在领域授权层硬拒绝，而不只依赖提示词。会话上下文按档案和标的隔离；调用前必须展示将发送的数据清单。

数据库密钥、BYOK 密钥、备份口令不得进入日志、崩溃报告、会话内容和普通导出。备份不是旧 SQLCipher 文件的简单封装：应用先导出不含设备密钥的可移植 SQLite 快照，再将整个载荷用 Argon2id 派生密钥和 AES-256-GCM 加密。恢复时先认证口令、校验载荷与 Schema，再使用目标设备生成的新数据库密钥写入新的 SQLCipher 文件；失败不得覆盖原档案或留下可见的半成品。

## BYOK 数据边界

- 服务商地址、模型、会话、上下文清单、代理运行、草稿和Token用量保存在当前档案的加密数据库中。
- API Key只保存在操作系统密钥库；浏览器模拟模式不会接收或保存密钥，加密备份也不包含密钥。
- 同一备份文件以密文 SHA-256 指纹登记；重复导入返回首次恢复的隔离档案，不重复登记成交。恢复为新档案 ID 时，成交幂等键及其引用在单一数据库事务内同步重绑定。
- 每次发送前显示实际Responses端点、模型、包含字段、明确排除字段和序列化大小；用户确认后才发送。
- Rust后端忽略前端提供的账本上下文，重新从当前档案读取持仓和现金。会话ID一旦绑定档案和标的，不能跨作用域复用。
- 远程Base URL必须为HTTPS；仅回环开发端点允许HTTP。禁止URL内嵌凭据、查询参数和片段，并禁止HTTP重定向。
- 请求固定`store: false`，不注册任何模型工具。外部内容或提示注入只能影响草稿文本，不能改变领域权限、正式策略、建议状态或成交账本。
- 成功调用以单一事务写入`DRAFT`成果、用量和审计；失败调用记录稳定错误类别，但不记录API Key或服务商原始错误正文。

## 在线行情

在线行情按档案配置，默认关闭。端点仅允许 HTTPS（回环契约测试除外），禁止 URL 内嵌凭据、查询参数、片段和 HTTP 重定向；请求超时为10秒。可选 Bearer 密钥只存系统密钥库且不进入备份。响应必须符合 `{price,currency,observed_at}` 合约，且为正价格、HKD、非未来时间；失败请求不会写入或覆盖已有快照，人工录入始终可用。

## MCP

专家 MCP 策略默认关闭并逐工具授权。允许类别仅为读取、分析和创建草稿；文件写入、外部消息、正式状态修改和交易相关类别即使出现在配置或外部提示中也会被拒绝。外部返回内容不参与权限计算。首版保留策略模型和审计边界，但不开放服务器连接界面。

漏洞请按 [SECURITY.md](../SECURITY.md) 私下报告，不要在公开 Issue 中提交密钥、持仓或原始数据库。
